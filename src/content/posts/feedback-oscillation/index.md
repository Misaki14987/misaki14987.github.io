## 反馈的图

```
x (输入) ──►( Σ )── e ──►[ 放大器 A(jω) ]──┬──► y (输出)
              ▲ −                          │
              │                            │
              └──────[ 反馈网络 β(jω) ]◄───┘
                     fb = β·y
```

Σ 是真实存在的电路节点，比如运放的差分输入对，硬件上确实在做"输入减反馈"这个动作：e = x − fb。

A(jω) 是放大器本身的增益，直流可以很大（运放能到 10⁵、10⁶ 这个量级），但频率一高就往下掉，原因下面讲相位来源那节会具体推。

β(jω) 是反馈网络。最简单的实现是输出端接两个电阻分压，采样后送回 Σ，这时 β=R1/(R1+R2) 是个跟频率没关系的实数；网络里塞了电容电感就不一样了，β 也会变成带相位的复数。

e 不是输入信号本身，是"输入减掉反馈之后剩下的那一点误差"，放大器实际在放大的是这个误差，不是原始的 x。

## 推一下闭环增益

三个关系式直接从图上抄下来：

```
e  = x − fb        …(1)  Σ点
fb = β·y           …(2)  反馈网络
y  = A·e           …(3)  放大器
```

把 (2) 代进 (1)：`e = x − β·y` ……(4)

再把 (4) 代进 (3)：`y = A(x − β·y) = A·x − A·β·y`

把带 y 的项挪到一边：`y + A·β·y = A·x`，也就是 `y·(1+A·β) = A·x`

两边除掉：

```
y/x = A / (1 + A·β)
```

这个 y/x 就是闭环增益，记 A_CL。分母里的 Aβ 先不急着起名字，它叫什么要看怎么把它实测出来，下一节就是干这个的。

```
A_CL(jω) = A(jω) / (1 + A(jω)β(jω))
```

## 环路增益 T 到底是怎么测出来的

把 fb 送回 Σ 之前那根线剪断，输入 x 设成 0，从剪口塞一个测试信号 T_in 进去，让它假装是 fb 流进 Σ。

这里有个坑，我一开始就是漏了这步：Σ 不会因为这是"测试"就不干活，它照样在做减法，`e = x − (流进来的信号) = 0 − T_in = −T_in`。这个负号很容易被顺手忽略，但漏掉它，后面巴克豪森准则算出来的临界相位就会差 180°（是 360° 还是 180° 的争论，根源就在这一步，下面会再提一次）。

−T_in 经过 A 变成 −A·T_in，再经过 β 变成 −A·β·T_in，绕回到剪口。

绕一圈回来的信号除以注入的信号，等于 −A(jω)β(jω)。把这个比值定义为环路增益：

```
T(jω) := −A(jω)β(jω)
```

这也是"环路增益"这个名字的来源，工程师拿网络分析仪剪开环路打信号，测绕一圈回来的幅度和相位，测到的就是这个 T，不是 Aβ 本身，因为 Σ 那个减法在测试时也在起作用。

代回闭环公式（Aβ=−T）：

```
A_CL(jω) = A(jω) / (1 − T(jω))
```

## 正反馈和负反馈只差一个符号

同样的结构，求和点是加还是减，结果差很远：

|      | 负反馈 e=x−βy          | 正反馈 e=x+βy            |
| ---- | ------------------- | --------------------- |
| 闭环公式 | A/(1+Aβ)            | A/(1−Aβ)              |
| 会不会炸 | A、β 是正实数时分母永远>1，不会炸 | Aβ=1（纯实数就够，不需要相位）直接炸  |
| 炸的性质 | 需要额外的相位条件才会不稳定，见下文  | 施密特触发器那种直接冲到底的闩锁，不是振荡 |

就差一个符号，结果却是"震荡"和"闩锁"这两种完全不同的东西，这也是为什么这个减号不能随手糊弄过去。

## 相位是从哪来的

"电路里有电容所以有相位"这话等于没说，具体是这样的。最简单的相位来源是一个 RC 低通：

```
H(jω) = 1 / (1 + jω/ω₀)        ω₀ := 1/(RC)，叫"极点频率"
```

拆成模长和相位：

```
|H(jω)| = 1 / √(1+(ω/ω₀)²)
∠H(jω)  = −arctan(ω/ω₀)
```

| ω     | ω/ω₀ | ∠H(jω)          |
| ----- | ---- | --------------- |
| 0（直流） | 0    | 0°              |
| ω₀    | 1    | −45°            |
| →∞    | →∞   | →−90°（渐近，永远够不到） |

一个 RC 极点最多贡献接近 90° 的相位滞后，够不到 90°。

真实放大器里有好几级、好几个寄生电容，相当于好几个极点串起来，相位是直接加的。代几个具体数字看看：两个极点 ω1=1、ω2=100（单位无所谓，只看比例），A0=1000：

| ω         | ∠A(jω)   | \|A(jω)\| |
| --------- | -------- | --------- |
| 1 (=ω1)   | ≈−45.6°  | ≈707      |
| 100 (=ω2) | ≈−134.4° | ≈7.1      |
| 10000     | ≈−179.4° | ≈0.001    |

最后一行是关键：相位快摸到 −180° 的时候，幅度已经掉到 0.001，离 |T|=1 差了十万八千里。这不是巧合。两个极点的相位理论上只能一直逼近 −180°，真要碰到得 ω→∞，可是幅度早在那之前跌没了。

所以有个结论：只有两个极点的放大器，不管 β 怎么取，永远凑不齐"相位到 180°"和"|T|=1"同时发生，所以是无条件稳定的。模拟IC设计里运放做"主极点补偿"，靠的就是这条数学结论撑着。三个或更多极点就不一定了，相位可能在幅度跌完之前就冲过 −180°，这才是真正会因为 β 选得不同而震荡或不震荡的情况。

## 相位滞后怎么把负反馈变成正反馈

有个数学事实：相位偏移 180°跟"变号"是一回事，旋转180°等于乘以−1。

负反馈那个"−"号，只有在没延迟（低频，相位偏移接近 0°）的时候才真的是"−"。频率升高，绕一圈的相位滞后刚好凑够 180° 的时候，这个"−"在数学上已经悄悄变成了"+"。电路一根线都没改，但在这一个频率点上，物理上已经是正反馈了。

类比一下荡秋千：想在秋千荡回来的时候拉住它，这是负反馈，对着干。但如果反应delay了恰好半个周期，这一拉的时机就从"拉住"变成"顺势推一把"，想刹车，延迟却把你变成了助推器。

## 巴克豪森准则，从"分母=0"直接推出来

回到 A_CL=A/(1−T)，分母趋近 0，增益炸掉，需要：

```
1 − T(jω) = 0
T(jω) = 1
```

T 是复数，写成极坐标 `T=|T|·e^(j∠T)`，1 的极坐标是 `1·e^(j0°)`。两个复数相等，模长和角度要分别相等，自动拆成两个条件，这就是巴克豪森准则

```
|T(jω)| = 1              （模长条件）
∠T(jω) = 0°（= 360°）    （相位条件）
```

物理意义对应前面剪开环路打信号那个实验：T=1 就是绕一圈回来的信号跟打进去的一模一样，把外部信号源撤走，它自己也能在环里一直转下去，这就是自激振荡。

## 相位裕度

定义 ω_gc：|T(jω_gc)|=1 恰好成立的那个频率。危险点在 ∠T=0°，相位裕度就是当前相位离 0° 还差多远，不用再加减 180°：

```
PM := ∠T(jω_gc)
```

- ∠T(ω_gc)=0° → PM=0°，零安全边际
- ∠T(ω_gc)=60° → PM=60°，安全
- ∠T(ω_gc)=−20° → PM=−20°，已经在震荡了

为什么不能只看 A 的大小：炸不炸取决于"模长=1"和"相位=0°"在同一个频率上同时发生。脱离具体频率点，A 或 T 的绝对值大小没有意义，现实里很多放大器在很多频率上 |T| 都远大于 1，完全正常。相位裕度把这整套关系压成一个数：增益刚好到临界值的那个频率上，相位离危险点还有多远。这就是为什么工程上盯着这一个数，而不是盯着 A 有多大。

## 震荡到底发生在哪个频率

### 噪声只是打火的火星

敲一下音叉或者玻璃杯，敲击本身什么频率都有一点（broadband），但听到的响声几乎是个纯音，因为音叉、杯子的结构只对自己的共振频率有响应，别的频率一下就死掉了。

反馈环是一样的道理：噪声（热噪声、电源纹波之类）本身就带着所有频率的微弱成分，不存在"这个噪声会震荡那个不会"这种说法。反馈环像个筛子，专挑满足 ∠T=0°(360°) 且 |T|≥1 的那一个频率，每绕一圈放大一次，其余频率因为相位不对或者增益不够，每绕一圈都被削弱，很快死掉。噪声只是点火的火星，真正决定震荡在哪个频率的是环路本身的相位-增益结构。

### RC 相移振荡器，自己推一下频率

3 级独立 RC 低通串起来（级间有缓冲，互不加载），每级 H(jω)=1/(1+jω/ω₀)，总相位是 −3·arctan(ω/ω₀)。

A 是纯实数增益，自身相位 0°，所以 Aβ 的总相位就等于 β 的总相位。要让 T=−Aβ 的相位卡在 0°，需要 Aβ 的相位是 −180°：

```
−3·arctan(ω/ω₀) = −180°  →  arctan(ω/ω₀)=60°  →  ω = √3·ω₀
```

这个频率下每一级的幅度是 1/√(1+3) = 1/2，三级串起来就是 1/8。要让 |T|=1，放大器增益就要把这 1/8 衰减补回来，A=8（实际设计会留点余量，比 8 大一些，确保能从噪声可靠起振，之后靠饱和限幅把振幅稳住）。震荡频率完全由 R、C 决定，跟噪声长什么样没关系。

### LC 槎路振荡器，接的是差分电感那部分

并联 L、C、损耗电阻 R，导纳：

```
Y(jω) = 1/R + j(ωC − 1/(ωL))
```

虚部为零（阻抗变成纯实数，相位=0°）的条件是 `ω₀ = 1/√(LC)`，这时候 Z=R，是全频段的最大值——一旦离开这个点，虚部一冒出来，|Z| 立刻往下掉。

LC 槎路在同一个 ω₀ 上同时锁死"相位刚好是 0°"和"幅度刚好最大"这两件事，天然就是巴克豪森条件要求的结构，长在一个元件里。损耗 R 越小（品质因子 Q 越高），这个峰越尖，筛选越狠，震荡频率也越纯净。这里的 L 可以直接用差分电感，Zd 算准了，直接就能决定振荡器输出频率 ω₀=1/√(L_diff·C)。

### 放大器"意外"震荡

同一套数学倒过来看：放大器里没人故意塞 LC 槎路，但寄生电容、引线电感天生就在那，等于电路自己偷偷带了个没设计过的频率选择结构。相位滚到临界角的那个频率不是挑出来的，是寄生参数自己凑出来的，通常就落在放大器标称带宽附近或者更高一点。设计失误就是，在这个意外的频率点上，相位裕度不够，|T| 还 ≥1，"该稳定的地方"就变成了"意外的振荡器"。跟精心设计的 LC 振荡器走的是完全一样的物理路径，只是选频率的元件从故意变成了意外。
